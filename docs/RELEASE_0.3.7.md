# Veilark Windows 0.3.7 — release evidence

Release date: 2026-08-23

## Scope

- Rebuilds Home around one centered action spine and enlarges the circular
  connect/stop control from 100 to 120 dp without changing the Material 3 color
  system or the compact 600×440 shell.
- Keeps status, engine, grouped server selection and Add/Refresh/Ping controls
  in a predictable vertical reading order; diagnostic detail follows the main
  controls instead of displacing them.
- Fixes the foreign branch of TrustTunnel `RussiaDirect`: unknown foreign TCP
  connections no longer enter the fake SNI upstream before the VPN endpoint.
- Keeps core inspection for known exclusion candidates and bounded background
  pre-resolution for RU exclusions.
- Preserves the MTU generated by TrustTunnel or supplied by an imported profile
  instead of replacing it with a client-wide value.
- Preserves the 0.3.x MSI UpgradeCode, DPAPI state and additive built-in Veilark
  Trust migration.

## Automated and static gates

- 40 shared and 80 helper JVM tests pass with zero failures; one documented
  shared environment test is skipped. Desktop compilation and Gate A smoke pass
  without starting a live tunnel.
- All, Manual, RussiaDirect and RussiaVpn generated sing-box configurations pass
  bundled sing-box 1.13.14 `check` with bundled RU SRS data.
- An isolated 600×440 RU idle render verifies the centered 120 dp action and
  control hierarchy. A second EN degraded render verifies long localization;
  the observed diagnostic displacement was corrected after that bounded pass.
- The `impeccable` layout detector reports no findings after implementation.
- Production EXE/MSI build passes. MSI administrative extraction contains
  sing-box 1.13.14, TrustTunnel/setup wizard 1.1.5-rc.6, WinTUN and both pinned
  RU SRS files. The verification bootstrap extracts, hashes and removes its
  payload when compiled with a non-elevating verification manifest.
